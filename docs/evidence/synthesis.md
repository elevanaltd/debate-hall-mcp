## Anti-Patterns to Avoid

### 1. Substituting Iteration for Dialectic

**Don't:** Run multiple passes with the same agent accumulating context.

**Why:** M018 showed iteration scores 21 points lower (66.5 vs 87.5) even with equal cognitive budget. Iteration refines the same perspective; dialectic transcends.

### 2. Same-Model Debates

**Don't:** Use Claude for all three roles.

**Why:** M019 showed each model has distinct cognitive strengths. Cross-domain pattern generation differs from systematic validation differs from transcendent synthesis.

### 3. Skipping Synthesis

**Don't:** Stop after Wind explores and Wall validates.

**Why:** The emergent properties come from Door's synthesis. The "Staged Sovereignty Model" and "Holographic Shard" solutions emerged only in synthesis phase.
