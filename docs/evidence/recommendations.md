## From M018: Use Dialectic, Not Iteration

**Evidence:** [Dialectic vs Iteration Study](./dialectic-vs-iteration-study.md)

**Finding:** Dialectic (d=2.1) significantly outperforms iteration, even when controlling for model differences.

**Recommendations:**

1. Use Wind/Wall/Door for problems with genuine tensions or trade-offs
2. Don't substitute iteration - it refines but doesn't transcend
3. Let Door synthesize - emergence happens in the synthesis phase
4. Expect novel solutions - outputs should be inversions or reframings, not just combinations

## From M019: Match Models to Cognitive Modes

**Evidence:** [Model Cognitive Optimization Study](./model-cognitive-optimization-study.md)

**Finding:** 29% quality improvement with optimized model assignment.

**Recommendations:**

1. Use Claude for PATHOS/Wind (creative exploration)
2. Use GPT for ETHOS/Wall (constraint validation)
3. Use Gemini for LOGOS/Door (synthesis)
4. If using single model, Claude provides best all-around performance
